# Lógica de programação com JavaScript — Alura

Exercícios introdutórios de programação com JavaScript executado diretamente no navegador, usando funções, variáveis, condicionais, loops e entrada com `prompt()`.

## Exercícios

| Arquivo | Objetivo |
| --- | --- |
| [`ano_copa.html`](./ano_copa.html) | Listar anos em intervalos de quatro anos a partir de 1930 |
| [`calculo_imc.html`](./calculo_imc.html) | Praticar entrada de peso/altura, cálculo e classificação por faixa |
| [`futebol.html`](./futebol.html) | Calcular pontos a partir de vitórias e empates |
| [`jogo_adivinha.html`](./jogo_adivinha.html) | Adivinhar um número sorteado em até três tentativas |
| [`media_idades_familiares.html`](./media_idades_familiares.html) | Calcular a média de idades informadas |
| [`tabuada.html`](./tabuada.html) | Gerar a tabuada de sete com um laço `for` |

## Como executar

Abra qualquer arquivo HTML no navegador e siga as perguntas exibidas. Não é necessário instalar Node.js ou iniciar servidor. Atualize a página para reiniciar o exercício.

## Limitações

Os exercícios não validam todas as entradas. O cálculo de IMC usa `^`, que em JavaScript é XOR bit a bit, e não potência; portanto, esse arquivo não fornece um cálculo de saúde confiável. O exercício de Copa do Mundo usa intervalos regulares, sem tratar exceções históricas.
